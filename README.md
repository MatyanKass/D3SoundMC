# D3Sound для Minecraft

Переписанный звуковой движок Minecraft: вместо панорамирования по расстоянию —
честное распространение звука по геометрии мира.

Мод для **Fabric, Minecraft 26.1.2**, Java 25.

Физика взята из [D3Sound](https://github.com/MatyanKass/D3Sound) — настольного
стенда, где она отлажена и проверена числами: время прихода звука совпадает с
расчётом до долей семпла, поглощение воздуха сходится с таблицами ISO 9613-1,
уровень диффузного поля — с классической формулой в пределах 1 дБ, а межушные
задержка и разница уровней ложатся на измеренные HRTF. Здесь эти модели
переносятся в игру.

## Почему Minecraft — удачная площадка

* Моддинг официальный: Fabric и Mixin позволяют заменить звуковой тракт целиком.
* Воксельный мир — это готовая акустическая геометрия. Вместо обхода дерева по
  треугольникам работает трассировка по сетке блоков (DDA), она на порядок дешевле.
* У блоков уже есть тип звука (камень, дерево, шерсть, стекло, снег, листва) —
  прямое соответствие таблице материалов с поглощением, рассеянием и
  звукоизоляцией по октавам.
* Источников в кадре единицы, а не сотни: бюджет на честную физику есть.

## Архитектура

```
звук игры ──► [Mixin: перехват] ──► [геометрия мира: воксельная трассировка]
                                          │
                                          ▼
                              [физика: прямой путь, окклюзия,
                               дифракция, отражения, поле]
                                          │
                                          ▼
                        [свой бинауральный микшер] ──► OpenAL
```

1. **Перехват.** Mixin в звуковой системе клиента: каждый звук приходит к нам с
   позицией, категорией, громкостью и высотой тона.
2. **Мир.** Блоки вокруг слушателя читаются как акустическая сетка; материал
   берётся из типа блока.
3. **Физика.** Прямой путь с окклюзией и дифракцией, ранние отражения,
   диффузное поле и импульсная характеристика по октавным полосам.
4. **Рендер.** Собственный микшер с задержками на каждое ухо (ITD), частотно
   зависимой тенью головы и свёрткой хвоста; на выход — один стерео-поток.

## Оптимизация

* воксельный DDA вместо дерева треугольников;
* сетка акустических зондов: импульсная характеристика считается для узлов и
  интерполируется, а не пересчитывается на каждый шаг игрока;
* пересчёт в фоновом потоке по бюджету времени;
* спатиализуются только слышимые источники, остальные идут упрощённо.

## Сборка

```bash
./gradlew build          # jar в build/libs
./gradlew runClient      # запуск клиента с модом
```

Нужен JDK 25 (Minecraft 26.x на нём). Путь к нему прописан в `gradle.properties`.
