# D3Sound для Minecraft

*[English version](README.en.md)*

Звуковой движок Minecraft, переписанный на честную физику: вместо панорамирования
по расстоянию — распространение волны по реальной геометрии мира.

Мод для **Fabric, Minecraft 26.2**, Java 25. Только клиент, на сервере не нужен.

Физика взята из [D3Sound](https://github.com/MatyanKass/D3Sound) — настольного
стенда, где она отлажена и проверена числами: время прихода звука совпадает с
расчётом до долей семпла, поглощение воздуха сходится с таблицами ISO 9613-1,
уровень диффузного поля — с классической формулой в пределах 1 дБ, а межушные
задержка и разница уровней ложатся на измеренные HRTF.

## Что слышно

Не «эффекты», а следствия физики — каждое из них можно выключить отдельно.

* **Направление и расстояние.** Собственная бинауральная модель: задержка между
  ушами (ITD), тень головы по частотам, спад по закону обратных квадратов.
* **Воздух.** Скорость звука и поглощение по температуре, влажности и давлению.
  Под водой звук вчетверо быстрее и почти не гаснет, в Нижнем мире быстрее на
  треть, в Энде медленный и вязкий, в лаве глухой.
* **Огибание преград.** Волновой фронт по свободным клеткам ищет кратчайший
  обход; на кромке звук теряет по Маекаве — тем больше, чем выше частота.
  Поэтому из-за угла слышно глухо, а не тихо.
* **Проход сквозь стену.** Волна давит на стену, стена колеблется целиком и
  переизлучает звук с другой стороны. Сколько теряется — задаёт звукоизоляция
  материала, толщина считается по закону массы (+6 дБ на удвоение). Сквозь
  шерсть слышно почти всё, сквозь камень — 54 дБ потерь, один бубнёж.
* **Звук по блокам.** Тот, из-за которого слышно соседей: стена раскачивается у
  источника и излучает у слушателя. Приходит раньше воздушного (3200 м/с) и
  слышится из стены, а не со стороны источника.
* **Отражения.** Трассировка лучей от слушателя с ламбертовым рассеянием.
  Раннее эхо приходит с направления настоящей стены, а не как обезличенный гул.
* **Помещение.** Время реверберации по Эйрингу из статистики самих лучей.
  Улетевший в небо луч засчитывается как полное поглощение — поэтому под
  открытым небом эха нет даже среди сплошного камня.
* **Доплер.** Из настоящего времени пробега волны, а не из формулы поверх.

## Архитектура

```
звук игры ──► [Mixin: перехват] ──► [снимок блоков вокруг слушателя]
                                          │
                                          ▼
                        [решатель в фоновом потоке: обходные пути,
                         проход сквозь стены, звук по блокам,
                         отражения, время реверберации]
                                          │
                                          ▼
                        [бинауральный микшер] ──► OpenAL
```

Игровой поток только снимает мир и позиции; вся физика считается в отдельном
потоке и публикуется целиком, так что микшер всегда видит согласованное
решение. В аудиопотоке нет ни аллокаций, ни обращений к миру.

## Нагрузка

Движок сам следит, сколько он ест, и держится в отведённой доле процессора:
свободна машина — растут лучи, глубина отражений и частота пересчёта; система
загружена или прогон затянулся — отступает резко. Вверх качество ползёт
медленно, вниз падает сразу: лучше на секунду потерять в точности, чем уронить
кадры.

Рычаги, если автоподбор не устраивает: доля процессора, потолок общей загрузки,
ручное качество, дальность расчёта и период пересчёта.

## Настройки

Открываются из стандартных настроек звука. У каждого пункта есть пояснение при
наведении. Ноль на числовом ползунке всегда означает «Авто».

Готовые наборы: «Реалистичный (High)», «Реалистичный (Low)», «Среднее»,
«Экономия производительности», «Высокое качество». Набор просто расставляет
ползунки разом; громкость, счётчик на экране и сам выключатель движка он не
трогает.

Экран настроек также показывает моды, которые спорят за звук, и насколько
серьёзно они мешают.

## Проверка

```bash
./gradlew bench          # числовой стенд: 68 проверок, ни звука в динамики
./gradlew build          # jar в build/libs
./gradlew runClient      # клиент с модом
```

Стенд считает ровно то же, что движок в игре, но сверяет цифры со справочниками
и формулами: таблицы ISO 9613-1 по воздуху, формула Эйринга по помещению,
измеренные ITD по голове, законы сохранения по трассировке. Ни один тест не
играет звук в динамики.

Нужен JDK 25 (Minecraft 26.x на нём). Путь прописан в `gradle.properties`.
